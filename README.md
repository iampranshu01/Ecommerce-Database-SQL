# Ecommerce-Database-SQL

## Project Overview

A capstone project focused on designing and managing a relational e-commerce database using MySQL and SQL.

The project manages customer, product, order, order item, and payment data and demonstrates how SQL can be used to retrieve and analyze business information from a structured database.

## Database Structure

The database consists of five related tables:

- Customers
- Products
- Orders
- Order Items
- Payments

Primary keys and foreign keys are used to establish relationships between tables and maintain data integrity.

## Key SQL Concepts

- Database and table creation
- Primary Key and Foreign Key
- INSERT statements
- JOIN operations
- WHERE filtering
- GROUP BY
- ORDER BY
- Aggregate functions such as `SUM()` and `COUNT()`
- Sales and customer analysis

## Analysis Performed

The project includes SQL queries to analyze:

- Total revenue
- Revenue by product
- Top customers by spending
- Best-selling products
- Cancelled orders


## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## Project Objective

To build a structured e-commerce database and use SQL queries to perform basic business analysis related to revenue, customers, products, and orders.
